# Offline data provenance

## Bundled city catalog

`CityCatalog` (303 entries) is generated by `tools/generate_city_catalog.py` from [GeoNames cities15000](https://download.geonames.org/export/dump/) and `countryInfo.txt`, downloaded 2026-09-24 (`cities15000.zip` SHA-256 `3FCCD5FCE541F51291502E3392A6E759957B338FC44ACFF0DA85BD17D26FA817`, `countryInfo.txt` SHA-256 `93BAFC525813F22E4711FF9ED6D626343094CE48C26388DC7C49189B3D7D5512`). It holds every capital GeoNames marks (feature code PPLC, 241 countries and territories) plus the 15 most populous places on each inhabited continent, using GeoNames' continent codes. City sections (PPLX) and sub-city districts (PPLA3/PPLA4) are skipped in the population ranking. The original ten entries, selected 2026-09-23 from an earlier download (SHA-256 `B65DFE6346A77C2CE628C34CE74FAB5F4081E393A1B82783C5192C40FD811E1C`), keep their stable IDs. GeoNames population figures follow administrative boundaries, so some cities count a whole municipal area. The entries retain GeoNames names, WGS84 coordinates, and IANA time-zone IDs; the app uses its own stable IDs. The same script writes `app/src/main/assets/timezone_points_v1.bin`: the rounded coordinates and IANA zone of every cities15000 place (33,901 points). When a place is saved from the globe, the nearest of these within 800 km suggests its time zone. The suggestion can be wrong near borders, and the user can change it. GeoNames data is [CC BY 4.0](https://www.geonames.org/export/); attribution: © GeoNames contributors. The app does not use the GeoNames web service or send saved places to it.

## Plate boundaries

The offline layer is a simplified derivative of Peter Bird's PB2002 plate-boundary model (Bird, 2003, doi:10.1029/2001GC000252), converted and distributed by Hugo Ahlenius/Nordpil and GeoJSON contributor csterling in [fraxen/tectonicplates](https://github.com/fraxen/tectonicplates). That collection is [Open Data Commons Attribution License 1.0](https://github.com/fraxen/tectonicplates/blob/master/LICENSE.md). Source GeoJSON URL: `https://raw.githubusercontent.com/fraxen/tectonicplates/master/GeoJSON/PB2002_boundaries.json`, downloaded 2026-09-23, SHA-256 `42B3E0876A7E40F133E958BA7AB85F8851B5C693A046FBC3B138E7751863D92A`. `tools/preprocess_plate_boundaries.py` documents the deterministic simplification command. The asset keeps all 241 line features, simplified from 6,292 to 2,491 points at 0.08° planar tolerance; rendering interpolates the segments on the sphere. Boundary types are not displayed because most source features have an empty type. This is a generalized educational model, not a site-specific hazard assessment.

Sunrise/sunset uses the [NOAA approximation](https://gml.noaa.gov/grad/solcalc/solareqns.PDF) with a 90.833° apparent zenith. The daylight readout is approximate and can differ with local horizon and atmospheric conditions.
